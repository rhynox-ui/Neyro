Neyro Terminal

Neyro Terminal is a non-custodial web interface for the NEAR blockchain. It lets token creators and holders create NEP-141 tokens through a public NEAR token factory, send tokens to many accounts, and launch tokens on NEARly.

Every transaction is reviewed and signed in your own NEAR wallet. Neyro never asks for a seed phrase, recovery phrase or private key, and never takes custody of funds.
